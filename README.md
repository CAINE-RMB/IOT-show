# IOT‑show
ESP32野营智能小车开源学习项目

## 项目简介
本项目为个人学习实践开源作品，基于ESP32实现一台野营智能小车。项目全部代码对外开放，仅用于学习交流，不做任何商业化用途。

仓库包含两部分资源：
- ESP32野营车代码：小车下位机主控程序
- 野营车小程序：配套微信小程序控制端

## 硬件说明
- 主控芯片：ESP32
- 项目性质：个人IoT学习演示，非商用产品

## 项目文件结构
├── ESP32 野营车代码 / 111     # ESP32 小车下位机源码
├── 野营车小程序             # 微信小程序前端代码
└── README.md                # 项目说明文档
