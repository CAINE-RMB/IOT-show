================================================================================
  华为云设备数据与指令下发 — 简易小程序需求（精简版）
================================================================================

目标：做一个简单的小程序，能够
  1. 接收华为云平台的数据（温度、湿度等，后续如果有增加就会）
  2. 向设备下发指令（前、后、左、右）

不包含：管理后台、数据库、OBS、复杂鉴权与多子项目；仅「小程序 + 后端代理 + 华为云 IoTDA」。


================================================================================
一、整体架构
================================================================================

  ┌──────────────────┐         ┌──────────────────┐         ┌──────────────────┐
  │  微信小程序       │  request │  Node 后端      │  HTTPS  │  华为云 IoTDA     │
  │  展示温湿度       │ ──────► │  代理华为云 API   │ ──────► │  设备影子 / 命令  │
  │  下发前后左右     │         │                  │         │  温湿度 / 指令    │
  └──────────────────┘         └──────────────────┘         └──────────────────┘


================================================================================
二、功能范围
================================================================================

（1）接收数据
  • 数据来源：华为云物联网平台「设备影子」中设备上报的属性。
  • 需要展示的内容：温度（℃）、湿度（%）。
  • 实现方式：小程序请求后端「获取设备数据」接口 → 后端调华为云设备影子 API → 解析 reported 中的 temperature、humidity → 返回给小程序展示；支持刷新、下拉刷新、上次更新时间。

（2）下发指令
  • 指令类型：前、后、左、右（与华为云产品模型中定义的命令一致，如 direction: up/down/left/right 等）。
  • 实现方式：小程序选择方向后请求后端「下发命令」接口 → 后端调华为云同步命令 API → 将结果返回给小程序提示成功或失败。


================================================================================
三、技术栈（精简）
================================================================================

| 部分       | 技术选型与说明 |
|------------|----------------|
| 小程序     | 微信小程序原生；WXML + WXSS/SCSS；逻辑层用 Page + wx.request 请求后端；不直连华为云、不存放任何密钥。 |
| 后端       | Node.js + Express；提供 /api/sensor（获取温湿度）、/api/control（下发前/后/左/右）；IAM Token、设备影子、命令 API 均在 backend 内调用。 |
| 华为云     | 物联网 IoTDA：设备影子（读温湿度）、同步命令（下发表单：前/后/左/右）；鉴权使用 IAM 用户名+密码或 AK/SK，仅配置在后端 .env。 |


================================================================================
四、开发前准备（华为云侧）
================================================================================

□ 产品 ID、设备 ID — 在华为云物联网平台完成设备创建与 MQTT 通讯测试
□ 设备属性 — 产品模型中定义温度、湿度等属性，设备上报到影子
□ 命令定义 — 产品模型中定义「方向」类命令（如前/后/左/右），用于下发
□ IAM — 在华为云统一身份认证中创建子用户或使用主账号，取得用户名、密码（或 AK/SK）
□ 项目 ID（project id）— IAM 鉴权与 IoT API 调用时必需
□ 区域（region）— 如 cn-north-4，与 IoT 控制台一致

以上信息可集中在「接口信息.txt」与后端 .env 中对照填写。


================================================================================
五、接口约定（小程序 ↔ 后端）
================================================================================

（1）获取设备数据（温湿度）
  • 方法：GET
  • 路径：/api/sensor
  • 响应：{ code: 0, data: { temperature, humidity }, message }
  • 说明：后端内部调华为云设备影子 API，解析 reported 中的 temperature、humidity 后返回。

（2）下发指令（前/后/左/右）
  • 方法：POST
  • 路径：/api/control
  • 请求体：{ direction: "up" | "down" | "left" | "right" }（或与华为云产品模型一致的枚举）
  • 响应：{ code: 0, data, message }
  • 说明：后端内部调华为云同步命令 API，将 direction 下发给设备。


================================================================================
六、实施步骤摘要
================================================================================

第一步：华为云控制台 — 创建产品/设备、定义属性（温湿度）与命令（前/后/左/右），完成 MQTT 测试，记录设备 ID、项目 ID、区域等。
第二步：IAM — 准备鉴权信息（用户名、密码或 AK/SK）、项目 ID，写入后端 .env。
第三步：后端 — 实现 IAM 取 Token、设备影子查询、命令下发；提供 GET /api/sensor、POST /api/control。
第四步：小程序 — 页面展示温湿度卡片与「上次更新」时间；提供「获取设备影子」「设备命令下发」等按钮，通过 wx.request 调用后端接口。
第五步：开发调试 — 后端运行在 localhost:3000 时，在微信开发者工具中勾选「不校验合法域名」；真机/上线前将后端部署为 HTTPS，并在微信公众平台配置 request 合法域名。

七、与当前仓库（111-wx）的对应关系
================================================================================

  • miniprogram/  — 小程序：首页展示温湿度、提示信息、三个按钮（获取 token 校验后端、获取设备影子、设备命令下发），wx.request 请求 backend。
  • backend/      — 后端：Express + routes/api.js（/sensor、/control）+ services/huawei-iam.js、huawei-iot.js，配置来自 .env。
  • 接口信息.txt  — 华为云相关 ID、区域等备忘，与 .env 对照。
  • 代码构成说明.md — 代码结构与数据流说明。

当前实现已满足本需求：仅接收温湿度 + 下发前/后/左/右，无管理后台、无数据库、无 OBS，结构简单清晰。
